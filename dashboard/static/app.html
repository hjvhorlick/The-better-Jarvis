The Brain — Gemini API keys
Paste your Gemini API key. It is saved to config/api_keys.json (the file the desktop app and every action read; ./.env is updated as well when it holds the key) and is used immediately — no restart. Below: where the key in use comes from, and the model in use.
Checking… Second Gemini key — fallback (optional). All calls use the first key. If Google refuses the first key with a 429 (its quota) or rejects the key, JARVIS switches to this one and goes back to the first key when its cooldown is over (a 429 cools the key down for 10 minutes; a rejected key waits until local midnight). Note: it only doubles the real Google allowance if it comes from a different Google account/project — a second key from the same project shares the same quota.
Checking… Checking the day's count… The count above is this app's own tally of calls that went out to Google today (voice and local answers are free and never counted). It only warns when it passes the warning level (SUPPER_GEMINI_DAILY_WARN, default 20) — it never stops a call. The only thing that can pause a call is Google itself: a real 429 cools that key down for 10 minutes and then it is tried again, and the chat message then is a short line saying Google stopped us.

Clear Glass & Yellow Lines — every surface
The glass is clear: you look through it at the room, or at your own camera when it is on, and the thin yellow line is what tells you where a pane ends. Three kinds of surface, two sliders each. Transparency: 0% is invisible glass, 90% is a smoked pane. Sand-blast: a little frost cleans the picture up; a lot of sand makes the pane milky, so nothing behind it can be read — private, not transparent. The yellow line and the bloom (the glow that lifts a pane off the dark) are set once, for all of them, and your numbers are remembered on this computer.
